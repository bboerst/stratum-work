# stratum-work-collector

![Version: 0.3.0](https://img.shields.io/badge/Version-0.3.0-informational?style=flat-square) ![AppVersion: v1.0.7](https://img.shields.io/badge/AppVersion-v1.0.7-informational?style=flat-square)

A Helm chart for deploying the Pool Work Collector (collector-go). 0.3.0: the Python implementation is gone, so
`implementation` and `goImage` are removed (`image` is the Go image and `image.tag` is required), and the collector
rejects the old MongoDB flags (`--db-url`, `--db-name`, `--db-username`, `--db-password`).
